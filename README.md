# Announcement Board Project - приватная доска объявлений

Держите своих пользователей в курсе событий с полной защитой от посторонних глаз. Self-hosted лента новостей для приватных сервисов.

## Особенности веб-приложения

На данный момент реализован следующий функционал:

- Бэкенд на `FastAPI`
- Telegram-бот для выпуска одноразовых кодов доступа
- `PostgreSQL` для хранения постов и данных пользователей
- `Argon2id` хэширование админ-пароля и одноразовых кодов
- HttpOnly cookie sessions
- `Rate limiting` на логине и OTP-верификации
- Фронтенд на `Svelte` с современным UI в стиле **glassmorphism**
- Поддержка Markdown-разметки с очисткой посредством `DOMPurify`
- Админ-панель для создания постов и управления белым списком ТГ-аккаунтов
